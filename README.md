# ინეს ბაღი — საშემოდგომო ზეიმის მოსაწვევი

ანიმაციური მოსაწვევი მშობლებისთვის (5–6 წლის ჯგუფი): ჯადოსნური კარი, მელოდია, ჩამოცვენილი ფოთლები.

- `index.html` — მთელი გვერდი (CSS + JS შიგნითაა)
- `assets/fonts` — FiraGO (Book, Bold, ExtraBold), ქართულ-ლათინური subset
- `assets/img` — ლოგო (mask) და ფოტოები

## თარიღი და დრო
`index.html`-ში მოძებნეთ:

```js
const EVENT = { date: "5 ნოემბერი", day: "ხუთშაბათი", time: "09:30" };
```

ჩაწერეთ, მაგ. `{ date: "15 ნოემბერი", time: "12:00" }` — ცარიელი ველები გვერდზე არ ჩანს.
